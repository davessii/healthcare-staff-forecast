# Данные и происхождение

В публичной версии используются только искусственные данные, создаваемые
`scripts/make_demo_data.py`. Названия «Демо регион» вымышлены; числа не являются
статистикой Росстата и не описывают реальные регионы.

В исходном архиве был подготовленный региональный CSV за 2010-2024 годы.
Исходных выгрузок и воспроизводимого скрипта объединения в архиве нет,
поэтому происхождение каждой строки не проверено и этот CSV не опубликован.
Также не публикуются старые сохранённые модели и таблицы их качества.

Для собственных данных нужен CSV `data/processed/healthcare_dataset_model_ready.csv`.
Поля: region, year, population, doctors_count, nurses_count, visits_count,
hospital_beds, outpatient_capacity, doctors_per_10000, nurses_per_10000,
beds_per_10000, visits_per_person. Один регион и год должны встречаться один раз;
годы в пределах региона должны идти без пропусков для корректных годовых лагов.
После замены CSV нужно выполнить `python model_training.py` заново.
