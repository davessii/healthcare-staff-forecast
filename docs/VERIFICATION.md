# Проверка публичной версии

Дата: 2 ноября 2026 года.

На искусственном наборе из 180 строк выполнено обучение двух целевых моделей с сопоставлением пяти алгоритмов. Все четыре unit-теста подготовки данных пройдены. Через Streamlit AppTest последовательно открыты все пять экранов, исключений нет. Прогноз на пять лет содержит пять строк и положительные значения численности.

Это проверка работоспособности программы, а не подтверждение точности на настоящих регионах. Рабочие модели и таблицы метрик создаются на компьютере пользователя и исключены из Git.
